# Installation

## Requirements

- Go 1.21 or higher
- A supported database (PostgreSQL, MySQL, SQLite, or DuckDB)

## Install lit

```bash
go get github.com/tracewayapp/lit/v2
```

## Database Drivers

lit works with standard `database/sql` drivers. Install the driver for your database:

### PostgreSQL

```bash
# pgx (recommended)
go get github.com/jackc/pgx/v5/stdlib

# or pq
go get github.com/lib/pq
```

### MySQL

```bash
go get github.com/go-sql-driver/mysql
```

### SQLite

```bash
go get github.com/mattn/go-sqlite3
```

### DuckDB

```bash
go get github.com/marcboeker/go-duckdb/v2
```

DuckDB uses `?` placeholders like SQLite, but its Go driver does not support
`LastInsertId()` — lit reads generated ids back with a `RETURNING id` clause (like
PostgreSQL), so auto-increment `id` columns should be sequence-backed
(`DEFAULT nextval(...)`).

You can also use a [custom driver](/guides/custom-drivers) to support databases not listed above.

## Verify Installation

Create a simple program to verify everything is working:

```go
package main

import (
    "fmt"
    "github.com/tracewayapp/lit/v2"
)

type User struct {
    Id    int
    Name  string
    Email string
}

func main() {
    lit.RegisterModel[User](lit.PostgreSQL) // or lit.MySQL, lit.SQLite, lit.DuckDB
    fmt.Println("lit installed successfully!")
}
```

Run it:

```bash
go run main.go
```

If you see "lit installed successfully!", you're ready to proceed to the [Quick Start](/getting-started/quick-start).
